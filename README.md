# n5-vocabulary-tracker
A website to track and study Japanese JLPT N5 vocabulary

# Concept Brief
N5 Vocabulary tracker is a website designed to help beginner Japanese learners to study and keep track of japanese vocabulary. The website will mark words and track overall progress.

# Teck Stack

- Frontend: HTML, CSS, Javascript
- Backend: Python
- Database: SQLite
- Testing: pytest
- Package Manager: pip
- Version Control: Git and Github
- Development Environment: Visual Studio Code
- AI Coding Tool: GitHub Copilot
