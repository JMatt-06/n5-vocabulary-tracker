# n5-vocabulary-tracker
A website to track and study Japanese JLPT N5 vocabulary

## Run locally

```sh
python -m pip install -r requirements-dev.txt
python app.py
```

Open <http://127.0.0.1:8000>. Vocabulary added through the form is persisted in `vocabulary.sqlite3`.

Run the test suite with `python -m pytest`.

# Concept Brief
N5 Vocabulary tracker is a website designed to help beginner Japanese learners to study and keep track of japanese vocabulary. The website will mark words and track overall progress.

# Teck Stack

- Frontend: HTML, CSS, Javascript
- Backend: Python
- Database: SQLite
- Testing: pytest
- Package Manager: pip
